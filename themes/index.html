Make your own theme

A theme renames and re-skins the whole game. It can change faction names, regions, resources, colours, ship and station names, weapon and ability names, and the art of every ship. It never changes how the game plays. Every theme plays the same, so you can turn the war into pirates, insects, sea creatures or your own invented universe.

A theme is one text file in JSON format. You can write it by hand, start from an example, or have an AI write it for you.

Before you start

  • Importing and using your own themes is part of the Full Game unlock (Main menu ▸ Themes).
  • You need a way to edit a plain-text file. On a computer, any text editor works (Notepad, TextEdit in plain-text mode, VS Code). On Android, use any plain-text or code editor app, or write the file on a computer and copy it to your phone.
  • Save the file with a .json extension, for example pirates.json.

Three ways to make a theme

1. Start from an example (easiest)

  1. Download the example that's closest to what you want. For example, rename-a-few for a few renames.
  2. Change the id and name at the top, so your theme doesn't replace the example.
  3. Edit the text inside the quotes. Look up any id you need in the theme reference. For example, the Vardek tier 4 warship is vardek_t4.
  4. Import it (see Importing your theme).

2. Ask an AI

  1. Open the AI prompt builder.
  2. Pick a task, fill in your idea and copy the prompt into a new chat with your AI assistant. Attach THEME_REFERENCE.txt.
  3. Copy the JSON the AI writes into a new .json file, then import it.
  4. If the Themes screen lists problems, use the Fix problems prompt.

3. Write it from scratch

Every theme starts like this:

{
  "format": "convergence-theme",
  "id": "my-theme",
  "name": "My Theme",
  "author": "Your name",
  "description": "One line shown in the Themes menu.",
  "factions": { },
  "units": { }
}

Fill in factions and units using the ids from the theme reference. You only include what you change. Anything you leave out keeps its built-in name and look.

How the pieces fit together

Factions are keyed by a fixed id (concord, vardek, helios…):

"vardek": {
  "title": "Comet Raiders",          // full name
  "short": "Raiders",                // used on buttons and in messages, so keep it short
  "group": "The Outer Dark",         // menu heading; factions with the same group are listed together
  "resourceA": "Ice",                // mined from crystal moons by freighters
  "resourceB": "Slag",               // extracted from asteroid fields by mining stations
  "color": "FF6A3A",                 // shields, jump flashes and blast effects
  "blurb": "Cheap, aggressive raiders who hide in comet tails and board their prey.",
  "weapons":   { "bolt1": "Ice Cannon", "torp1": { "name": "Comet Torpedo", "color": "A0E0FF" } },
  "abilities": { "cloak": "Comet Tail", "boarding": "Boarding Hooks" },
  "shipStyle":    { "form": "BLADE", "hull": "8A8E96" },
  "stationStyle": { "shape": "ANGULAR" }
}

Units are keyed by <faction>_<slot>. Ships are scout, constructor, freighter, warships t1…t8 (t8 is the flagship), and t1_launched for carrier fighters. Stations are hq, shipyard, research, adv_shipyard, refinery, mining, defense and sensor.

"vardek_t1": "Skiff",                                          // name only
"vardek_t8": { "name": "The Long Night", "desc": "Flagship of the {faction}." }

Placeholders. In descriptions and blurbs (not in names), the game fills in {resourceA}, {resourceB}, {faction}, {count}, {duration}, {spawn} and {advancedShipyard} with real values.

Ability descriptions are optional. If you leave desc out, the game writes an accurate one for you.

Art

You don't have to draw anything. Each faction's ships are generated from its shipStyle. Larger tiers automatically get bigger hulls, more decks and more detail. Try these first:

Field Try
form (hull shape) WEDGE DART NEEDLE SPINDLE BLADE CRESCENT SLAB ORB SHARD SEED MANTA HAMMER TRIDENT ARROW CLUSTER
capitalForm Same choices; used for tiers 5-8
wings NONE SWEPT FORWARD DELTA STRAIGHT CANARD FINS CLAWS SPINES RING
engines SINGLE TWIN QUAD BANK RING
plating NONE PANELS GREEBLES RIBS FACETS
organic true for smooth, living-looking hulls with glowing veins
hull panel dark light engine glow rim Colours
seed Any number. Change it to reshuffle the small details

If you give only colours, each ship keeps its built-in shape. For full control, draw ships with vector shapes. See hand-drawn-art and the "Explicit art" section of the file format page.

Colours are hex codes like "FF6A3A". Any online "colour picker" shows them. Space is black, so keep hulls mid-tone or lighter, or set a light rim (outline) colour.

Importing your theme

  1. Put the .json file on your phone, for example in Downloads or Google Drive.
  2. In the game, open Main menu ▸ Themes ▸ Import file… and pick the file.
  3. Select the theme in the list and tap Use this theme.

Updating a theme. Import the edited file again. If it has the same id, it replaces the old copy. To remove a theme, select it and tap Delete twice.

When something goes wrong

What you see What to do
"Not valid JSON" A missing comma, quote or bracket. The message gives the position. A JSON validator website or an AI (Fix problems prompt) will find it quickly. Comments (//) and trailing commas are allowed.
"The file has no factions or units" Check that your names are inside "factions": { … } or "units": { … }.
unknown faction "…" / unknown unit "…" in the problem list The id is misspelled or doesn't exist. Look it up in the theme reference.
Bad colour "…" Use 6 or 8 hex digits, e.g. "3A6BD8".
unknown value "…" for form, wings… Use one of the values from the table above.
A weapon or ability keeps its old name The key doesn't belong to that faction. Each faction has its own list in the theme reference.
{resourceA} shows up literally Placeholders only work in descriptions and blurbs, not in names.
Ships are hard to see Use lighter hull colours, or add a rim colour.

Problems that don't stop a theme from loading are listed on the Themes screen under the theme's details. Fix them and import the file again.

Sharing themes

Themes are ordinary files, so you can share them with friends any way you like. Please keep shared themes original, and don't use names or artwork from existing films, shows, games or books.
