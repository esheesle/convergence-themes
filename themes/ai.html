Make a theme with an AI

Any capable AI chat assistant can write a theme for you: Claude, ChatGPT, Gemini, Copilot and so on.

  1. Download THEME_REFERENCE.txt. It lists every id the AI is allowed to use.
  2. Pick a task below. Leave Include the rules block ticked when you start a new chat.
  3. Replace every <angle bracket> with your own idea. You can type straight into the box.
  4. Copy the prompt into the AI chat and attach THEME_REFERENCE.txt.
  5. Save the AI's answer as a .json file and import it.

If your AI can't take attachments, paste in just the sections of THEME_REFERENCE.txt for the factions you're changing. Each faction's section is self-contained.

Getting good results

  • Give the AI a strong concept. "Feudal space houses, each named after a gemstone" works better than "make it cooler".
  • Ask for a naming pattern per faction. For example "Clan ships are named after storms" or "the Accord uses virtues". It keeps names consistent.
  • Keep the id the same when you ask for changes. Importing the new file then replaces the old version instead of adding a copy.
  • Look out for invented ids. If the Themes screen says unknown unit "..." or unknown faction "...", the AI made up an id. Use the Fix problems prompt.
  • Check the colours in the game. AIs sometimes pick hull colours too dark to see. Ask for lighter hulls, or a rim colour.
  • Stay original. Themes you share with others shouldn't use names or designs from existing franchises.
