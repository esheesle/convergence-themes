Theme file format

A theme is a single JSON file that renames and re-skins the game. It can change:

  • faction names, region (menu group), resource names, faction colour and description,
  • ship and station names and descriptions,
  • weapon names and bolt/beam colours, ability names and descriptions,
  • ship and station art, either generated from a style or drawn explicitly.

It cannot change gameplay (stats, prices, abilities). Every theme plays identically.

A theme only needs what it changes. Anything missing falls back to the built-in theme (default.json), which is also the best complete example to copy.

Import a theme from Main menu ▸ Themes ▸ Import file…. Re-importing a theme with the same id replaces the old copy.

The reader is lenient: // line and /* block */ comments and trailing commas are allowed. Problems that don't stop the theme loading (an unknown unit id, a bad colour…) are listed on the Themes screen.

Smallest useful theme

{
  "format": "convergence-theme",
  "id": "my-names",
  "name": "My Names",
  "factions": {
    "concord": { "title": "The Blue League", "short": "League", "resourceA": "Starglass" }
  },
  "units": {
    "concord_t8": { "name": "Indomitable", "desc": "Flagship of the League." },
    "concord_t1": "Gnat"
  }
}

A unit entry may be just a string (its name).

Top level

Field Meaning
format "convergence-theme" (optional, checked if present)
id Stable id; also the file name it is stored under. Re-importing the same id replaces the old copy.
name, author, description Shown in the Themes menu
subtitle Tagline under the title on the main menu
factions Object keyed by faction id (below)
units Object keyed by unit id (below)

Factions

Faction ids are fixed (they identify the gameplay roster):

Region Faction ids
1 concord, accretion, shroud, vardek, saurak
2 helios, luminar, gloam, satrapy, myriad
3 seren, coalition, starwatch, lumen, thornkin, corvane, kharast

Each faction's play style is described by its blurb in the theme reference.

"concord": {
  "title": "Concord of Worlds",       // full name
  "short": "Concord",                 // used on buttons and in messages
  "group": "Meridian Sector",         // menu heading; factions with the same group are listed together
  "resourceA": "Aurorite",            // mined from crystal moons by freighters
  "resourceB": "Duralloy",            // extracted from asteroid fields by mining stations
  "color": "6FC8FF",                  // shields, jump flashes, area-blast effects
  "blurb": "Balanced fleets with ...",
  "weapons":   { "beam1": "Lance Emitter", "torp1": { "name": "Singularity Torpedo", "color": "6AB8FF" } },
  "abilities": { "cloak": "Phase Veil", "repair_field": { "name": "Emergency Repairs", "desc": "..." } },
  "shipStyle":    { ... },            // see "Generated art"
  "stationStyle": { ... }
}

Weapon and ability keys. Weapons are keyed per faction as beam1, beam2, bolt1, torp1…; abilities by type, numbered when a faction has several of one type: cloak, cloak2, jump, shield_boost3, absorb… The complete list for every faction is in the theme reference. A value can be a plain name or an object with name plus color (weapons) or desc (abilities). Leave out an ability's desc and the game writes an accurate one.

Colours are RRGGBB or RRGGBBAA hex, with or without #.

Units

Unit ids are <faction>_<slot>:

Slot Unit
scout, constructor, freighter Utility ships
t1 … t8 Warships by tier; t8 is the flagship. A second ship of the same tier is t2b.
t1_launched Fighter wing spawned by carriers (factions with fighter wings)
hq, shipyard, research, adv_shipyard, refinery, mining, defense, sensor Stations 
"concord_t3": {
  "name": "Hailstorm-class",
  "desc": "Heavy escort packed with torpedo launchers.",
  "weapons":   [ null, { "name": "Torpedo Rack", "color": "FF5A2A" } ],   // by position; null = keep
  "abilities": [ { "name": "Seeker Barrage", "desc": "..." } ],
  "art": { ... }                                                         // optional, see below
}

Per-unit weapons/abilities override the faction-wide names for that ship only.

Text placeholders work in any description or blurb: {resourceA}, {resourceB}, {faction} (short name), {count}, {duration}, {spawn} (the launched fighter's name; in ability text), {advancedShipyard}.

Generated art

Most themes only need a style per faction. The generator then draws every ship from the faction style plus the ship's role and tier: larger tiers get wider hulls, superstructure decks, bigger wings, pods and more detail.

shipStyle fields (all optional):

Field Values Meaning
form WEDGE DART NEEDLE SPINDLE BLADE CRESCENT SLAB ORB SHARD SEED MANTA HAMMER TRIDENT ARROW CLUSTER Hull silhouette
capitalForm same Hull for tier 5-8 (defaults to form)
wings NONE SWEPT FORWARD DELTA STRAIGHT CANARD FINS CLAWS SPINES RING Flank structures
engines SINGLE TWIN QUAD BANK RING Stern engine layout
plating NONE PANELS GREEBLES RIBS FACETS Surface detail
pods 0-2 Pairs of engine pods on pylons (from tier 3; the second pair from tier 6)
width 0.4-2.5 Hull width multiplier
organic true/false Smooth, wobbly outlines and glowing veins
windows true/false Window rows
core true/false Glowing reactor core
hull panel dark light engine glow colours Palette (light = windows, glow = energy details)
rim colour Outline colour (helps very dark hulls)
seed integer Changes the random details

stationStyle fields: shape (ROUND ANGULAR ORGANIC BLOCKY CRYSTAL), hull, panel, dark, light, glow, seed.

Style fields merge with the built-in theme's, so { "shipStyle": { "hull": "AA3333" } } recolours a faction and keeps its shapes.

A unit can override the generator for itself only:

"concord_t8": { "art": { "generator": "ship", "form": "TRIDENT", "wings": "DELTA", "variant": 7 } }

Extra fields here: kind (SCOUT CONSTRUCTOR FREIGHTER FIGHTER WARSHIP), tier, flagship, variant. Use { "generator": "station", "shape": "CRYSTAL" } for stations, and { "copy": "concord_t1" } to reuse another unit's art.

Explicit (hand-drawn) art

For full control, give a unit a vector design. Coordinates are art units: +x is the bow, +y is port, and the design is centred on (0, 0) inside a w × h box. The game scales the box's width to the ship's length, so only the proportions matter.

"art": {
  "w": 100, "h": 60,
  "palette": { "hull": "CDD2DA", "glow": "7FE0FF" },   // optional; use as "$hull"
  "rim": "8090A0",                                     // optional outline colour
  "flipX": false,                                      // mirror bow/stern when baking
  "parts":  [ ["poly", "$hull", 0.4, 0.8, 50,0, -50,25, -40,0, -50,-25] ],
  "accent": [ ["rect", "FFFFFF", 0, 0, 0,-3, 20,3] ],  // tinted with the player's colour
  "engines": [ ["$glow", -48, 0, 4, 1] ]               // [colour, x, y, radius, pulse 0/1]
}

Parts are drawn in order. shade (0-1) is how strongly a shape is lit toward its middle. outline is the edge width (0 = none). Names ending in M also draw a copy mirrored across the centreline.

Shape Arguments after the colour
poly, polyM shade, outline, x1, y1, x2, y2, x3, y3, …
ellipse, ellipseM shade, outline, cx, cy, rx, ry, rotationDeg
circle shade, outline, cx, cy, r
rect, rectM shade, outline, x0, y0, x1, y1
ngon shade, outline, cx, cy, r, sides, rotationDeg
spike, spikeM shade, outline, x, y, angleDeg, length, baseWidth, curveDeg
teardrop shade, outline, sternX, bowX, halfWidth, bluntness, cy
line, lineM width, x1, y1, x2, y2
glow, glowM cx, cy, r (soft additive-looking spot)
ring width, cx, cy, rx, ry
windows x1, y1, x2, y2, count, size

Every ship should have at least one accent part, so players can tell whose ship it is.
